# PSYnetworkanalysis

## This is the code to reproduce the results from *Novel tools for comparing the architecture of psychopathology between neurogenetic disorders: An application to X- vs. Y-chromosome aneuploidy effects in males*

Preprint available at https://www.medrxiv.org/content/10.1101/2025.01.10.25320352v2

The R file 'multilevel_analyses_psychopathology' reproduces Figures 1-3 and corresponding results.

The R file 'WSBM_psychopathology' reproduces Figure 4 and S1-S2 and corresponding results.

The R file 'permutation' reproduces the permutation used to calculate statistical significance against the null distribution with group assignment shuffled.

All necessary datafiles are included in the /data/ folder.
